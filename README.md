# Student Management Portal (MERN Stack)

A full-stack student management portal built using the MERN stack (MongoDB, Express.js, React.js, Node.js), allowing registration, profile management, and record handling with automated email notifications.

## Features
- Student registration with profile image upload
- View, update, and delete student records
- Automated email notification sent upon successful registration
- RESTful API integration between frontend and backend

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Other:** REST APIs, Email notification service

## How It Works
1. A student registers through the frontend form, including a profile picture upload.
2. The backend (Express.js + Node.js) processes the request and stores the data in MongoDB.
3. Upon successful registration, an automated email notification is sent to the student.
4. Admin/users can view, update, or delete student records through the portal.
